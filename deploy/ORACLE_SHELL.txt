=== Oracle: enable PagueloFacil webhook (one URL for WhatsApp + Telegram) ===
Public URL for Paguelofacil support: https://webhook.aideazz.xyz/paguelofacil-webhook

Add to /home/ubuntu/EspaLuzFamilybot/.env (after Paguelofacil sends CCLW):
  PAGUELOFACIL_CCLW=<merchant CCLW from Paguelofacil>
  PAGUELOFACIL_SANDBOX=false         # live production (same as Telegram /pagar)
  PAGUELOFACIL_AMOUNT=11.00
  PAGUELOFACIL_ACCESS_DAYS=30
  TELEGRAM_BOT_TOKEN=<same as familybot>
  INTERNAL_WEBHOOK_SECRET=<random secret — same in EspaLuzWhatsApp .env>
  PAGUELOFACIL_WA_NOTIFY_URL=http://127.0.0.1:8081/internal/paguelofacil-grant

Telegram users pay with: /pagar  (generates secure Paguelofacil checkout link)
WhatsApp users pay with: pagar   (same webhook, PARM_1=WA:phone)
Webhook auto-grants 30 days + platform notify (Telegram API or WhatsApp internal callback).

Add to /home/ubuntu/EspaLuzWhatsApp/.env:
  ESPALUZ_FAMILYBOT_PATH=/home/ubuntu/EspaLuzFamilybot
  PAGUELOFACIL_PAYMENTS_FILE=/home/ubuntu/EspaLuzFamilybot/paguelofacil_payments.json
  PAGUELOFACIL_WA_ENABLED=true
  INTERNAL_WEBHOOK_SECRET=<same as Familybot>
  PAGUELOFACIL_WA_NOTIFY_URL=http://127.0.0.1:8081/internal/paguelofacil-grant

After deploy: sudo systemctl restart espaluz-whatsapp espaluz-payments-webhook espaluz-familybot

On VM (Ubuntu), from repo /home/ubuntu/EspaLuzFamilybot:
  sudo apt-get update && sudo apt-get install -y python3-flask python3-dotenv python3-requests
  # OR: pip install -r requirements.txt (user/venv model you prefer)

  sudo cp deploy/espaluz-payments-webhook.service /etc/systemd/system/
  sudo systemctl daemon-reload
  sudo systemctl enable --now espaluz-payments-webhook
  sudo systemctl status espaluz-payments-webhook --no-pager

Verify locally on VM:
  curl -sS http://127.0.0.1:5000/health | head -c 200
  curl -sS http://127.0.0.1:5000/paguelofacil-webhook | head -c 300

Via public hostname (HTTPS must already terminate at nginx/cloudflare pointing to :5000):
  curl -sS https://webhook.aideazz.xyz/paguelofacil-webhook
  curl -sS -X POST https://webhook.aideazz.xyz/paguelofacil-webhook -H "Content-Type: application/json" -d "{\"test\":true}"

Nginx proxy example: see nginx-webhook.conf in repo (server_name webhook.aideazz.xyz -> proxy_pass http://127.0.0.1:5000).
That config sends ALL paths to :5000, so /paypal-webhook and /paguelofacil-webhook both reach the Flask app once espaluz-payments-webhook is running.

One-command rollout on VM after git pull Familybot/deploy:
  bash /home/ubuntu/EspaLuzFamilybot/deploy/oracle_rollout_payment_webhooks.sh

Journal logs:
  journalctl -u espaluz-payments-webhook -f
